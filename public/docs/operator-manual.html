⚠️ SAFETY WARNING
This system controls a high-speed attraction. Improper operation may result in equipment damage or safety violations. All operators must be trained and certified before operating this system.

1. System Overview

The VectorDyne Ride Control System consists of three interconnected PLCs:

  • Main Control PLC (Port 502): Manages ride sequencing, position tracking, and speed control
  • Safety PLC (Port 503): Monitors safety interlocks, emergency stops, and event triggers
  • Effects PLC (Port 504): Controls show lighting, audio triggers, and special effects
📘 NOTE: All three PLCs must be operational for normal ride operation. The Safety PLC has override authority and can halt operations at any time.

2. Daily Startup Procedure

Morning System Initialization

  1. Verify all three PLCs show green status indicators
  2. Check hydraulic pressure reads 1100-1300 PSI
  3. Confirm bearing temperature is below 30°C
  4. Enable Master Enable on Safety PLC
  5. Close safety gate and verify Safety Gate Closed indicator
  6. Press Start Command on Main PLC
  7. Monitor warmup sequence (approximately 10 seconds)
  8. Verify motor running and brake disengaged
⚠️ COMMON STARTUP ERRORS
Error 300: Safety PLC not ready - Ensure Safety PLC is enabled first
Error 301: Safety PLC lost during startup - Check network connection to Safety PLC
Error 210: Safety gate not closed - Verify physical gate closure

3. Normal Operation

3.1 Speed Control

Adjust vehicle speed by writing to the Speed Setpoint register (0-100%):

  • 0-30%: Station operations and loading
  • 30-50%: Normal cruise speed
  • 50-70%: High-speed segments (use caution)
  • 70-100%: Emergency operations only
📘 HINT: The system includes automatic speed ramping. Rapid changes may trigger unauthorized speed change detection in the Safety PLC.

3.2 Zone Management

The track is divided into three zones. Each zone can be independently disabled:

Zone Positions Description
Zone 1 0-8 Station and launch area
Zone 2 9-17 High-speed course
Zone 3 18-26 Brake and return
⚠️ WARNING: Disabling a zone while the vehicle is in that zone will trigger an alarm. Always plan zone changes during station stops.

4. Event System

The system features 9 programmable events triggered at specific track positions:

Event Position Function
Event 1 0-2 Loading Gate
Event 2 3-5 Safety Interlock Check
Event 3 6-8 Launch Accelerator
Event 4 9-11 Photo Flash Point
Event 5 12-14 Mid-Course Brake (max 70% speed)
Event 6 15-17 Track Switch
Event 7 18-20 Final Brake (max 50% speed)
Event 8 21-23 Station Approach (max 30% speed)
Event 9 24-26 Unload Platform

5. Emergency Procedures

5.1 Emergency Stop

  1. Press Emergency Stop Button on Safety PLC
  2. System enters State 4 (Emergency)
  3. Motor immediately stops, brakes engage
  4. Alert active, flash light activated
  5. To clear: Release E-Stop, system returns to IDLE

5.2 Controlled Shutdown

  1. Allow vehicle to reach station (position 0-2)
  2. Press Stop Command on Main PLC
  3. System enters State 3 (Stopping)
  4. Motor stops gracefully, brakes engage
  5. System returns to IDLE

6. Maintenance Indicators

Monitor these critical parameters during operation:

  • Motor Current: Normal range 50-130A
  • Bearing Temperature: Alert at 70°C, critical at 85°C
  • Hydraulic Pressure: Normal 1100-1300 PSI
  • Brake Wear: Replace at 100%
  • Vibration Level: Normal 10-20, warning at 30+
📘 MAINTENANCE TIP: Check brake wear every 100 cycles. High wear rates may indicate aggressive braking or speed control issues.

7. Troubleshooting

7.1 Common Issues

Vehicle Won't Start:

  • Verify Master Enable is ON
  • Check Safety Gate is closed
  • Ensure Emergency Stop is not pressed
  • Confirm all three PLCs show connected status

Excessive Alarms:

  • Review Event Log for patterns
  • Check if speed exceeds zone limits
  • Verify event enables match operational needs
⚠️ KNOWN ISSUE SB-2024-03: Under certain conditions, the Safety PLC may not properly validate event sequences. See Service Bulletin 2024-03 for workaround procedures.
