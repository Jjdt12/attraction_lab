SB-2024-07: Safety PLC Bypass Vulnerability

Issued: Oct 12, 2024 | Document: VDC-SB-2024-007

CRITICAL

Affected Systems: All VectorDyne control systems running firmware v3.1 or earlier

Issue Description:
Under specific conditions, the Safety PLC may accept commands that bypass normal safety interlocks. The issue occurs when certain holding registers (MW100-102) are set to specific values in sequence.

Impact:
System may operate with safety gate open or during other unsafe conditions. This represents a severe safety hazard and must be addressed immediately.

🔧 Temporary Workaround:
Until firmware update is available:
  1. Monitor Safety PLC registers MW100-102 continuously
  2. If values deviate from expected range (0-50), trigger immediate E-stop
  3. Implement additional monitoring on Safety Gate sensor
  4. Log all safety violations for investigation

Resolution:
Firmware update v3.2 scheduled for Nov 2024. Contact VectorDyne Technical Support to schedule update.

SB-2024-05: Event Sequence Validation Failure

Issued: Sep 28, 2024 | Document: VDC-SB-2024-005

WARNING

Affected Systems: Systems with Event Controller enabled

Issue Description:
The Safety PLC does not properly validate event trigger sequences. Events can be triggered out of order by manipulating the event enable registers directly, bypassing position-based logic.

Impact:
Show effects may trigger at incorrect positions. May cause guest confusion but poses no direct safety risk.

🔧 Known Workaround:
Event enables can be manually controlled by writing to coils %QX0.8 through %QX0.16. While not recommended for production use, this can be utilized for testing event sequences during maintenance windows.

Resolution:
Under investigation. No ETA for fix at this time.

SB-2024-03: State Machine Transition Exploit

Issued: Aug 15, 2024 | Document: VDC-SB-2024-003

CRITICAL

Affected Systems: All versions

Issue Description:
Main PLC state machine (register MW15) can be directly written to, bypassing normal state transitions. This allows forcing the system into running state without proper safety checks.

Impact:
Critical safety vulnerability. System may start with safety conditions not met.

🔧 Emergency Procedure:
If unauthorized state change detected:
  1. Immediately trigger emergency stop
  2. Review event log for state changes
  3. Verify all safety systems before restart
  4. Report incident to VectorDyne immediately
📘 TECHNICAL NOTE: Writing value 2 to MW15 will force RUNNING state. The Safety PLC should detect this but current firmware has gaps in detection logic.

Resolution:
Firmware patch in development. Deploy additional monitoring on MW15 as interim measure.

SB-2024-02: Zone Disable During Operation

Issued: Jul 22, 2024 | Document: VDC-SB-2024-002

WARNING

Affected Systems: Systems with multi-zone operation

Issue Description:
Disabling zones (coils %QX0.5, %QX0.6, %QX0.7) while vehicle is in the zone triggers alarm but does not stop vehicle movement. This can lead to unexpected behavior.

Impact:
Vehicle continues through disabled zone, may trigger additional alarms and affect show timing.

🔧 Operational Workaround:
Only modify zone enables when vehicle is at station (position 0-2). System will respect zone changes on next cycle.

Resolution:
Behavior is by design but documentation was unclear. Operator manual updated to reflect proper procedure.

SB-2024-01: Speed Setpoint Direct Write

Issued: Jun 10, 2024 | Document: VDC-SB-2024-001

INFO

Affected Systems: All versions

Issue Description:
Speed setpoint register (IW0) accepts values outside normal 0-100 range. Values above 100 are clamped to 100 but may cause momentary speed spikes during transition.

Impact:
Minor. Speed ramping logic prevents unsafe operation but may trigger unauthorized speed change detection.

🔧 Best Practice:
Always validate speed values before writing. Recommended range: 0-100. Values outside this range will be clamped but may appear suspicious in logs.

Resolution:
Input validation added in firmware v3.0 and later.

Reporting New Issues

If you discover a potential vulnerability or operational issue:

  1. Document the exact steps to reproduce
  2. Note all affected register addresses and values
  3. Capture relevant logs from Event Log
  4. Email details to: security@vectordyne.example.com
  5. For critical safety issues, call 1-800-VECTOR-1 immediately
