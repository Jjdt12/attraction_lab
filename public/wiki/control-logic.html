Control Logic Documentation

Last updated: November 5, 2025 | Owner: Michael Torres | Version: 3.1

State Machine Overview

The ride control system uses a finite state machine (FSM) with six primary states:

StateCodeDescriptionExit Conditions
IDLE0System powered, ready to startStart command received
STARTING1Pre-start safety checksAll checks pass
RUNNING2Normal ride operationPosition reaches 270 or stop command
STOPPING3Controlled decelerationVehicle at position 0
STOPPED4Vehicle stationary at stationReset command
ERROR99Fault detectedFault cleared and reset

Zone Control Logic

The track is divided into three zones for position-based control:

  • Zone 1 (0-90): Loading/Launch - Acceleration from station
  • Zone 2 (91-180): Main Experience - Primary show scenes
  • Zone 3 (181-270): Return/Unload - Deceleration and station approach

Zone Transition Rules

  • Only one vehicle allowed in system (single-vehicle operation)
  • Zone enables must be active before vehicle entry
  • Safety PLC monitors zone occupancy
  • Automatic braking if zone violation detected

Speed Control Algorithm

The speed controller uses a position-based profile:

  • Position 0-30: Ramp from 0 to 30 units/sec (loading)
  • Position 31-90: Accelerate to 100 units/sec (launch)
  • Position 91-180: Maintain 80-100 units/sec (cruise)
  • Position 181-240: Decelerate to 40 units/sec (approach)
  • Position 241-270: Decelerate to 0 units/sec (brake)

Safety Interlocks

The following conditions must be TRUE for operation:

  • Emergency stop NOT pressed (%QX0.3 = FALSE)
  • Safety gate closed (%QX0.4 = TRUE)
  • Safety PLC ready (%QX0.31 = TRUE)
  • Effects PLC ready (%QX0.32 = TRUE)
  • Master enable active (%QX0.0 = TRUE)
  • No active safety faults
📝 Note: Any change to control logic requires approval from both Control Systems Engineering and Safety Engineering teams. Test thoroughly in simulation before deployment.
