Control Logic Documentation

Last updated: November 5, 2025 | Owner: Michael Torres | Version: 3.1

State Machine Overview

The ride control system uses a finite state machine (FSM) with four primary states:

StateCodeDescriptionExit Conditions
IDLE0System powered, ready to startStart command received and safety PLC ready
STARTING1Pre-start safety checks and brake releaseStart timer exceeds 50 scans
RUNNING2Normal ride operationReturns to starting position, stop command, or safety fault
STOPPING3Immediate stop and brake engagementReturns to IDLE immediately
📝 Note: The system automatically cycles through one complete circuit (27 positions) before returning to IDLE state. Position wraps from 26 back to 0.

Zone Control Logic

The track is divided into three zones for position-based control:

  • Zone 1 (0-8): Loading/Launch - Station and initial acceleration
  • Zone 2 (9-17): Main Experience - Primary show scenes and effects
  • Zone 3 (18-26): Return/Unload - Station approach and return

Track Length: 27 positions (0-26) with automatic position wrapping

Zone Transition Rules

  • Only one vehicle allowed in system (single-vehicle operation)
  • Zone enables must be active before vehicle entry
  • Safety PLC monitors zone occupancy
  • Automatic braking if zone violation detected

Event Sequence

Nine ride events trigger based on proximity sensor detection:

EventSensorPosition RangeDescription
Event 1Proximity 10-3Loading Gate
Event 2Proximity 22-6Safety Interlock
Event 3Proximity 35-9Launch Accelerator
Event 4Proximity 48-12Photo Flash
Event 5Proximity 511-15Mid-Course Brake
Event 6Proximity 614-18Track Switch
Event 7Proximity 717-21Final Brake
Event 8Proximity 820-24Station Approach
Event 9Proximity 923-26Unload Platform

Event Control: Events are managed by the Safety PLC and can be individually enabled/disabled via coils 8-16 (event_1_enable through event_9_enable).

Speed Control Algorithm

The speed controller uses a ramped acceleration/deceleration profile:

  • Speed Setpoint: Default target speed is 50 units (configurable via %MW0)
  • Ramp Rate: 2 units per scan cycle (speed_ramp_rate)
  • Acceleration: Gradual ramp from 0 to target speed during STARTING/RUNNING states
  • Position Updates: Position increments every 2500 speed accumulator units
  • Speed Limits: Clamped between 0-100 units

Position Calculation: position_accumulator increments by actual_speed each scan. When accumulator reaches 2500, position increments by 1 and accumulator resets.

Safety Interlocks

The following conditions must be TRUE for operation:

  • Emergency stop NOT pressed (coil 3 = FALSE, %QX0.3)
  • Safety gate closed (coil 4 = TRUE, %QX0.4)
  • Safety PLC ready (read from %MW102 via SCADA bridge)
  • Effects PLC ready (read from %MW103 via SCADA bridge)
  • Master enable active (coil 0 = TRUE, %QX0.0)
  • All zone enables active (coils 5-7 for zones 1-3)

Inter-PLC Communication

The three PLCs communicate via Modbus TCP with a SCADA bridge:

  • MAIN PLC: Port 502 - Primary ride control and position tracking
  • SAFETY PLC: Port 503 - Safety monitoring and event management
  • EFFECTS PLC: Port 504 - Show effects and lighting control

The SCADA server bridges data between PLCs including proximity sensors, safety status, and event states.

📝 Note: Any change to control logic requires approval from both Control Systems Engineering and Safety Engineering teams. Test thoroughly in simulation before deployment.
