PLC Programming Guide

Last updated: November 10, 2025 | Owner: Michael Torres | Version: 2.4
⚠️ Warning: Only authorized personnel should modify PLC programs. All changes must be tested in simulation first.

Programming Standards

Project Nexus uses IEC 61131-3 Structured Text (ST) with OpenPLC Runtime.

Naming Conventions

  • Variables: lowercase_with_underscores
  • Constants: UPPERCASE_WITH_UNDERSCORES
  • Memory Tags: %QX (coils), %MW (registers)

Main Program Structure

(* MAIN CONTROL PROGRAM *) PROGRAM attraction_control_main VAR (* Modbus-mapped variables *) start_command AT %QX0.1 : BOOL; stop_command AT %QX0.2 : BOOL; motor_running AT %QX3.2 : BOOL; brake_engaged AT %QX3.3 : BOOL; (* Memory Words *) speed_setpoint AT %MW0 : INT; current_position AT %MW1 : INT; current_speed AT %MW2 : INT; state AT %MW15 : INT; (* 0=IDLE, 1=STARTING, 2=RUNNING, 3=STOPPING *) (* Bridge registers from other PLCs *) safety_plc_ready_reg AT %MW102 : INT; effects_plc_ready_reg AT %MW103 : INT; END_VAR (* State machine logic *) CASE state OF 0: (* IDLE *) motor_running := FALSE; brake_engaged := TRUE; IF start_command AND (safety_plc_ready_reg = 1) THEN state := 1; END_IF; 2: (* RUNNING *) motor_running := TRUE; brake_engaged := FALSE; (* Position updates automatically via accumulator *) END_CASE; END_PROGRAM

Memory Map

AddressVariableDescription
%QX0.0master_enableMaster system enable (Coil 0)
%QX0.1start_commandStart ride command (Coil 1)
%QX0.2stop_commandStop ride command (Coil 2)
%QX0.3emergency_stop_buttonE-stop status (Coil 3)
%QX0.4safety_gate_closedSafety gate status (Coil 4)
%QX3.2motor_runningMotor running status (Coil 26)
%QX3.3brake_engagedBrake status (Coil 27)
%MW0speed_setpointTarget speed (Modbus 1024)
%MW1current_positionVehicle position 0-26 (Modbus 1025)
%MW2current_speedActual speed (Modbus 1026)
%MW15stateState machine value (Modbus 1039)
%MW102safety_plc_ready_regSafety PLC status (Modbus 1126)
%MW103effects_plc_ready_regEffects PLC status (Modbus 1127)
📝 Note: %MW addresses are offset by 1024 in Modbus. For example, %MW1 maps to Modbus holding register address 1025.

Uploading to OpenPLC

  1. Save .st file in /scripts/
  2. Run: python upload_st_to_openplc.py program.st
  3. Verify at http://localhost:8080
  4. Click "Start PLC"
