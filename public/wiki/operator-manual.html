Operator Manual

Last updated: November 8, 2025 | Owner: Operations Team | Version: 2.1
⚠️ SAFETY FIRST: Never override safety systems. All operators must complete certified training before operating this attraction. In case of emergency, press the red EMERGENCY STOP button immediately.

Pre-Operation Checklist

Complete this checklist before starting daily operations:

Step 1: Visual Inspection
  • Walk the entire track - check for debris, damage, or obstructions
  • Inspect vehicle for damage, loose parts, or wear
  • Verify all emergency exits are clear and unlocked
  • Check that safety gates operate smoothly
  • Ensure all warning signs and safety markings are visible
Step 2: System Power-Up
  1. Turn on main circuit breakers in electrical room
  2. Power on control cabinet - wait for all three PLC ready indicators (green lights)
  3. Verify HMI screen displays "SYSTEM READY"
  4. Check that all status indicators show green on Multi-PLC Status panel
Step 3: Safety System Test
  1. Press EMERGENCY STOP button - verify immediate system shutdown
  2. Reset E-Stop and confirm system returns to ready state
  3. Test safety gate interlocks - system should not allow start with gate open
  4. Verify all nine ride events are enabled (Events 1-9 indicators should be green)
Step 4: Test Cycle
  1. Run empty vehicle test cycle
  2. Observe smooth acceleration, zone transitions, and final braking
  3. Listen for unusual noises (grinding, squealing, rattling)
  4. Verify all show effects trigger at correct positions
  5. Check that vehicle returns to station and brake engages

Starting a Ride Cycle

Prerequisites: System must show "READY" state, safety gate closed, no alarms active, Master Enable ON
  1. Ensure guests are properly seated with restraints secured
  2. Perform visual confirmation that all guests are ready
  3. Make announcement: "Please keep hands and arms inside the vehicle"
  4. Close and lock safety gate
  5. Click START RIDE button on HMI
  6. Confirm green "MOTOR RUNNING" indicator appears
  7. Monitor vehicle progress through zones on visualization panel

Normal Ride Stop

  1. Click STOP RIDE button (vehicle will complete cycle and return to station)
  2. Wait for vehicle to come to complete stop
  3. Verify "BRAKE ENGAGED" indicator is illuminated
  4. Open safety gate to allow guest exit

Emergency Stop Procedure

Use Emergency Stop for:
  • Guest attempting to exit moving vehicle
  • Loose article on track
  • Unusual sounds or visible mechanical issues
  • Guest medical emergency requiring immediate access
  • Any situation where continuing operation poses risk
  1. Press large red EMERGENCY STOP button immediately
  2. System will halt all motion within 2 seconds
  3. Make PA announcement: "Please remain seated, we are experiencing a temporary stop"
  4. Assess situation and determine if evacuation is needed
  5. Contact maintenance if mechanical issue suspected
  6. To reset: Twist E-Stop button clockwise, then click RESET RIDE on HMI

HMI Control Panel Guide

Control Purpose Notes
START RIDE Begin ride cycle Only available when system in READY state
STOP RIDE Controlled stop (completes cycle) Vehicle returns to station safely
EMERGENCY STOP Immediate system halt Use only in emergency situations
RESET RIDE Clear faults and return to ready Only use after resolving issue
Master Enable System power enable Must be ON for operation

Understanding Status Indicators

Multi-PLC Status Panel

  • Green: PLC connected and operating normally
  • Yellow: PLC connected but reporting warning
  • Red: PLC disconnected or critical fault

Ride State Machine

  • IDLE: System powered but not active
  • STARTING: Pre-start checks in progress
  • RUNNING: Normal operation, vehicle in motion
  • STOPPING: Controlled stop sequence
  • STOPPED: Vehicle at rest in station
  • ERROR: Fault detected, requires attention

Monitoring During Operation

Continuously monitor these indicators during ride operation:

Indicator Normal State Action if Abnormal
Motor Current 50-150 amps If exceeds 180A, initiate controlled stop
Speed 0-100 units/sec Monitor for unexpected speed changes
Bearing Temperature 25-85°C If exceeds 90°C, stop and call maintenance
Brake Pressure 1150-1250 PSI If below 1100 PSI, do not operate
Active Events Cycle through 1-9 If events stop triggering, investigate

Common Alarms

Alarm Code Description Response
ALM-001 Safety Gate Open Close gate, alarm will clear automatically
ALM-002 Emergency Stop Active Reset E-Stop button, then reset system
ALM-003 Motor Overcurrent Stop operation, contact maintenance
ALM-004 Safety PLC Not Ready Check Safety PLC status, may need restart
ALM-005 Position Sensor Fault Do not operate, contact maintenance immediately

End of Day Shutdown

  1. Complete all rides in progress
  2. Click RESET RIDE to return to IDLE state
  3. Turn Master Enable to OFF
  4. Document any issues or maintenance needs in operations log
  5. Lock control cabinet
  6. Turn off main circuit breakers
  7. Complete end-of-day checklist and submit to operations manager
📋 Required Training: All operators must complete "Nexus Operator Certification" (Course OPS-201) and pass practical exam before solo operation. Recertification required annually.
