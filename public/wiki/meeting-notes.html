Safety Review Meeting - November 8, 2025

Time: 2:00 PM - 4:00 PM | Location: Engineering Lab | Attendees: 8

Agenda: Review of safety interlock testing results and preparation for certification audit

Key Discussion Points:

  • E-Stop Testing: All 6 E-stop buttons tested under various conditions. Response time consistently under 100ms, well within spec of 200ms.
  • Zone Interlocks: Confirmed that multiple vehicle detection prevents collisions in all scenarios. Tested with deliberate attempts to bypass.
  • Gate Safety: Loading gate interlocks function correctly. Ride cannot start unless gate is fully closed and locked.
  • Failsafe Behavior: Simulated various failure modes (PLC fault, network loss, power interruption). System always defaults to safe state.

Findings:

  • PASS Emergency stop response time
  • PASS Zone collision prevention
  • PASS Safety gate interlocks
  • MINOR Need to add additional documentation for watchdog timer logic

Next Steps: Kwame will prepare comprehensive safety documentation package for external auditors.

Design Review: HMI Enhancements - November 5, 2025

Time: 10:00 AM - 11:30 AM | Location: Virtual (Zoom) | Attendees: 10

Purpose: Review proposed enhancements to operator HMI based on feedback from initial testing

Proposals Reviewed:

  • Enhanced Alarm System: Add color-coded severity levels and audio alerts for critical alarms. APPROVED
  • Trend Visualization: Real-time charts for speed, position, and system health metrics. APPROVED
  • Quick Actions Panel: One-click access to common operations (zone enable/disable, effect control). APPROVED WITH CHANGES - Must include confirmation dialogs for safety-critical actions
  • Multi-Monitor Support: Allow HMI to span multiple displays for better visibility. DEFERRED - Phase 2 feature

Operator Feedback: Alex reported that operators find the current interface intuitive but requested larger text for alarm messages and better contrast in dark mode.

Implementation Timeline: Approved changes will be implemented in Sprint 8 (Nov 13-27)

Technical Deep Dive: Multi-PLC Communication - October 30, 2025

Time: 1:00 PM - 3:00 PM | Location: Engineering Lab | Attendees: 6

Led by: Sarah Chen and Michael Torres

Topics Covered:

  • Modbus TCP Architecture: Detailed walkthrough of how the three PLCs communicate via Modbus TCP protocol
  • Coil Mapping: Explanation of coil and register assignments for each PLC and how they coordinate
  • Heartbeat Mechanism: How Safety and Effects PLCs signal readiness to Main PLC via Coils 31 and 32
  • Event Handshaking: Process by which Main PLC requests events (Coils 8-16) and Safety PLC confirms (Coils 17-25)
  • Fault Handling: What happens when communication is lost or a PLC becomes unresponsive

Hands-on Lab: Team used Modbus diagnostic tools to observe real-time communication between PLCs during ride operation

Documentation: Michael updated the PLC Programming wiki page with detailed communication examples
