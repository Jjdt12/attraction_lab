Network Topology

Last updated: October 25, 2025 | Owner: Sarah Chen | Version: 1.3

Network Overview

The Nexus control system uses an isolated industrial Ethernet network with dedicated VLANs for control traffic, ensuring deterministic timing and security.

IP Address Scheme

DeviceIP AddressPortPurpose
Main PLC192.168.1.10502Primary control logic
Safety PLC192.168.1.11503Safety monitoring
Effects PLC192.168.1.12504Show effects
HMI Server192.168.1.208765WebSocket interface
Network Switch192.168.1.1-Managed switch

Network Requirements

  • Bandwidth: 100 Mbps per PLC (1 Gbps switch)
  • Latency: <5ms between PLCs
  • Cabling: CAT6 shielded, max 100m runs
  • Redundancy: Dual-homed connections for critical devices
  • Isolation: Air-gapped from guest Wi-Fi and corporate networks

VLAN Configuration

  • VLAN 10: PLC Control Traffic (highest priority)
  • VLAN 20: HMI/SCADA Traffic
  • VLAN 30: Maintenance Access (restricted)

Security Measures

  • No internet connectivity on control network
  • MAC address filtering enabled
  • Port security on all switch ports
  • Modbus traffic encrypted via VPN for remote access
  • Annual penetration testing required
