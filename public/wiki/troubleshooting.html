Troubleshooting Guide

Last updated: November 8, 2025 | Owner: Maintenance Team | Version: 1.8
⚠️ Safety Notice: Always tag out and lock out power before performing any physical maintenance. If in doubt, contact a certified technician. Never bypass safety interlocks.

Quick Diagnostics

Use this flowchart for initial diagnosis:

  1. Does HMI show connection? → No: Check network cables and PLC power
  2. Are all PLCs green? → No: Identify which PLC(s) are offline, check specific section below
  3. Does Master Enable turn on? → No: Check E-Stop and safety gate
  4. Does START RIDE work? → No: Check ride state and prerequisites
  5. Does vehicle move smoothly? → No: Check motor current and brake release

Common Issues & Solutions

Issue 1: HMI Shows "WebSocket Disconnected"

Symptoms:
  • HMI displays red disconnection indicator
  • No real-time updates on screen
  • Controls non-responsive
Solution Steps:
  1. Check that WebSocket server is running on control PC (should be at localhost:8765)
  2. Open command prompt on control PC and run: python standalone_server.py
  3. Verify firewall is not blocking port 8765
  4. Check Ethernet cable from HMI terminal to control PC
  5. If problem persists, restart control PC and wait 30 seconds for boot

Prevention: Set WebSocket server to auto-start on boot using Windows Task Scheduler

Issue 2: Main PLC Shows Red/Disconnected

Symptoms:
  • Main PLC indicator shows red on Multi-PLC Status panel
  • Cannot start ride
  • System shows "PLC Connection Failed"
Solution Steps:
  1. Check that Main PLC is powered (green LED on PLC should be lit)
  2. Verify Ethernet cable connected to port 502
  3. Ping PLC: Open command prompt, type ping 127.0.0.1 (or actual PLC IP)
  4. Check OpenPLC Runtime is running (go to http://localhost:8080)
  5. Restart OpenPLC service if needed
  6. Review OpenPLC logs for errors at C:\OpenPLC\logs\

Common Cause: PLC watchdog timeout if program contains infinite loop or scan time exceeds limit

Issue 3: Ride Won't Start (Button Greyed Out)

Symptoms:
  • START RIDE button is disabled/greyed out
  • System shows "Prerequisites Not Met"
  • Ride state stuck in IDLE
Check These Prerequisites in Order:
  1. Master Enable: Must be ON (green indicator)
  2. Safety Gate: Must be closed (Coil 4 = TRUE)
  3. E-Stop: Must be reset (Coil 3 = FALSE)
  4. Safety PLC Ready: %MW102 must equal 1 (check Safety PLC connection on port 503)
  5. Effects PLC Ready: %MW103 must equal 1 (check Effects PLC connection on port 504)
  6. Previous Ride Complete: Vehicle must be at position 0
  7. No Active Alarms: Check Alarm Panel for any unacknowledged alarms

Tip: Use the "Modbus Coil States" panel to verify each prerequisite coil state

Issue 4: Vehicle Not Moving After Start

Symptoms:
  • START RIDE clicked but vehicle remains stationary
  • Motor Running indicator does not light
  • Motor current shows 0 amps
Solution Steps:
  1. Check that Brake Engaged coil (27) is FALSE - brake must release
  2. Verify motor contactor clicked (you should hear audible "click" in electrical cabinet)
  3. Check motor power circuit breaker - should be ON
  4. Inspect VFD (Variable Frequency Drive) for fault codes
  5. Check motor encoder cable - loose connection prevents motion
  6. Verify PLC output coil 26 (motor_running) is TRUE

Warning: If motor hums but doesn't move, stop immediately - possible mechanical jam

Issue 5: Ride Events Not Triggering

Symptoms:
  • Vehicle moves but show effects don't activate
  • Event Active indicators (Coils 17-25) stay off
  • Silent ride with no lights/sounds
Solution Steps:
  1. Check that all Event Enable coils (8-16) are TRUE
  2. Verify Safety PLC is connected (port 503)
  3. Verify Effects PLC is connected (port 504)
  4. Check position sensor - events trigger based on vehicle location
  5. Review Safety PLC logs for event processing errors
  6. Test individual effects manually using Attack Console (if available)

Note: Events require both Safety PLC (triggers) and Effects PLC (execution) to work

Issue 6: High Motor Temperature Warning

Symptoms:
  • Bearing Temperature shows >85°C
  • Alarm "WARN-TEMP-HIGH" appears
  • Unusual smell from motor area
Solution Steps:
  1. Immediate: Stop ride and let motor cool for 30 minutes
  2. Check that cooling fans are operating (listen for fan noise)
  3. Inspect motor vents for dust/debris blocking airflow
  4. Verify ambient temperature in control room (should be below 25°C)
  5. Check motor bearings for unusual noise or vibration
  6. If temperature exceeds 90°C, tag out and call maintenance

Prevention: Clean motor vents monthly, check bearing lubrication quarterly

Issue 7: Position "Jumping" or Incorrect

Symptoms:
  • Vehicle position display shows erratic values
  • Position jumps forward/backward unexpectedly
  • Events trigger at wrong locations
Solution Steps:
  1. Check encoder cable connection to PLC (loose connection is common cause)
  2. Inspect encoder for physical damage or dirt on disk
  3. Verify encoder power supply (should be 24VDC)
  4. Use oscilloscope to check encoder signal quality if available
  5. Recalibrate position by clicking RESET RIDE with vehicle at station (position 0)
  6. If problem persists, encoder may need replacement

Temporary Workaround: Reset ride to recalibrate position to 0 at station

Network Communication Issues

Intermittent PLC Disconnections

Possible Causes:

  • Bad Ethernet Cable: Replace with known-good cable, use CAT6 or better
  • Switch Port Failure: Try different port on network switch
  • EMI Interference: Ensure network cables are away from motor power cables
  • Network Storm: Check for broadcast storms or network loops
  • PLC Overload: Reduce Modbus polling rate if scan time >50ms

Diagnostic Tool: Use ping -t [PLC_IP] to monitor connection stability

Advanced Diagnostics

Using Event Log

The Event Log tab provides detailed system history. Look for:

  • CRITICAL events: Emergency stops, safety faults
  • WARNING events: Parameter out of range, communication delays
  • INFO events: Normal operations, state changes

Modbus Debugging

For advanced users - use Python scripts in /scripts/ folder:

  • probe.py - Test Modbus connectivity to any PLC
  • test_modbus_addresses.py - Verify address mappings
  • intercept.py - Monitor Modbus traffic in real-time

When to Call for Help

⚠️ Contact Maintenance Immediately If:
  • Smoke, burning smell, or sparks from any equipment
  • Unusual grinding, scraping, or banging noises
  • Vehicle fails to stop when commanded
  • Safety interlocks not functioning
  • Guest injury or potential injury situation
  • You're unsure about any repair procedure
