📋 1. Attraction Overview

Project Nexus represents the cutting edge of themed entertainment control systems. This immersive dark ride combines physical theming, advanced automation, and theatrical show effects to create a 4-5 minute guest journey through nine distinct show scenes.

🎯 Key Specifications

  • Type: Tracked dark ride with automated vehicle
  • Track: Continuous circuit, 27 positions (0-26)
  • Duration: 4-5 minutes per cycle
  • Scenes: 9 distinct themed environments
  • Zones: 3 operational zones
    • Zone 1: Positions 0-8 (Loading & Launch)
    • Zone 2: Positions 9-17 (Main Show)
    • Zone 3: Positions 18-26 (Finale & Return)
  • Capacity: 6 passengers per vehicle
  • Throughput: ~600 guests/hour
  • Protocol: Modbus TCP/IP

MAIN PLC Port 502

Responsibilities: Master coordinator, state machine, position tracking, speed control, event sequencing

Key Signals: Register %MW102 (Safety PLC Ready), Register %MW103 (Effects PLC Ready)

SAFETY PLC Port 503

Responsibilities: E-stop monitoring, gate interlocks, zone occupancy, event validation

Safety Level: SIL-2 target (Dec 2025)

EFFECTS PLC Port 504

Responsibilities: DMX lighting, audio triggers, special effects, projection mapping

🔒 6. Safety Systems

  • Layer 1: Physical E-stop buttons (6 stations)
  • Layer 2: Safety PLC interlocks
  • Layer 3: Main PLC operational safety
  • Layer 4: Watchdog monitoring
  • Layer 5: Fail-safe design

🚨 Emergency Procedure

  1. Press E-stop OR write TRUE to coil 3
  2. Verify motion stopped, brakes engaged
  3. Assess situation
  4. Clear E-stop (FALSE to coil 3)
  5. System returns to IDLE
  6. Document incident

📖 9. Quick Reference

START: 1. master_enable (0) = TRUE 2. safety_gate_closed (4) = TRUE 3. All zones (5-7) = TRUE 4. All events (8-16) = TRUE 5. speed_setpoint (reg 0) = 50 6. start_command (1) = pulse 7. Check safety_plc_ready_reg (reg 1126/%MW102) = 1 8. Check effects_plc_ready_reg (reg 1127/%MW103) = 1 STOP: stop_command (2) = pulse E-STOP: emergency_stop (3) = TRUE NOTE: PLC ready status uses memory word registers (MW102/MW103), NOT coils. These are bridged from other PLCs via SCADA.
